# Guadalupe Miró — Portfolio site brief

## Goal
A Next.js + React portfolio, deployed on Vercel, repo on GitHub. Built collaboratively with Claude Code, with every step explained (Guadalupe is new to code).

## Stack
- Next.js + React
- Deploy target: Vercel
- Repo: GitHub

## Style direction
- Fully minimal, mostly neutral (black/white), Apple-like restraint — not the colorful/maximalist route
- Light UI, no dark/black backgrounds
- Simple sans-serif typography, sentence case throughout, generous white space
- Staggered/asymmetric card grid (not everything aligned to a strict grid) — more visual interest, referenced from deadpine.xyz and cristinamartinezpaz.com
- Simple footer: icon-only links (Behance, LinkedIn, GitHub, email)

## Reference sites (what to borrow from each)
- **deadpine.xyz** — tag-filter row, staggered card grid, cards that behave differently (some link out, some open a "process" page), minimal footer icon row
- **chaachiedesigns.framer.website** (Jackson Ringger) — case study narrative template: cover (role/timeline/tools) → "View case study" anchor → long-form narrative with punchy one-line section headers, inline images, pull-quotes, a stats callout, closing CTA
- **hellodani.co** — cautionary reference: too much personality/color competes with the work itself. Avoid the hover-carousel and duplicate "tiny fraction of work" sections.
- **iaragrins.com** — hover-to-preview list interaction is interesting but her site reads as confusing overall; use with restraint if at all
- **cristinamartinezpaz.com** — closest existing precedent to Guadalupe's own Tumblr; white space + hover card interaction


### Case study template (from Chaachie reference)
1. Cover: project name, role, timeline, tools
2. "View case study" anchor / scroll cue
3. Context/problem narrative — punchy one-line section headers
4. Process — research, exploration, iteration, images interspersed with narrative text
5. Solution — final UI/flows
6. Outcome — stats or reflection callout if available
7. Closing CTA / link to next case study
